# ROS 2 실습 — TF2

## 01. turtle_tf2_demo

### 목표
좌표 프레임(frame)이 여러 개일 때 그 사이 관계가 어떻게 관리되는지 확인

### 환경
ROS 2 (Humble), Ubuntu (Linux)

### 코드
직접 작성한 코드 없음. ROS 2 기본 제공 예제 사용:
- `turtle_tf2_py` 패키지의 `turtle_tf2_demo.launch.py`

### 실행
터미널 1:
```
ros2 launch turtle_tf2_py turtle_tf2_demo.launch.py
```

### 결과
거북이 두 마리가 뜨고, 방향키로 turtle1을 움직이면 turtle2가 따라옴. turtle2에는 "따라가라"는 명령이 직접 주어진 게 아니라, 
TF에 turtle1의 위치를 계속 물어보고 그 방향으로 이동하는 구조임.

`tf2_echo turtle2 turtle1`로 두 프레임 사이 관계를 조회하면 Translation과 Rotation 값이 실시간으로 갱신됨. 
turtle2 → turtle1 관계는 아무도 직접 발행하지 않았는데도 조회가 되는데, 각 거북이의 world 기준 위치로부터 TF2가 트리를 타고 계산해 준 값임.


### 마무리
좌표 프레임이 여러 개 있을 때, 프레임 사이의 모든 관계를 일일이 발행하지 않아도 된다는 것을 확인했다. 
각 프레임이 부모와의 관계만 발행하면, 그 사이에 직접 연결이 없는 두 프레임의 관계도 TF2가 트리를 따라 계산해 준다.

turtle2가 turtle1을 따라간 것도 위치를 직접 전달받아서가 아니라, TF에 관계를 조회한 결과로 움직인 것이었다.
